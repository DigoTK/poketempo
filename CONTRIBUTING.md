# Contributing
Include host/game/mod versions, settings, installation method and steps to reproduce in bug reports. Redact personal paths from logs. Do not upload game files, keys or private saves.

Run the checks in [Development](docs/DEVELOPMENT.md). Document changed behavior and test using a backup save. Keep native configuration usable without Node, preserve PT-BR/English strings, disclose AI assistance and retain third-party credits. Contributions are intended for MIT distribution; only share material you may license.
